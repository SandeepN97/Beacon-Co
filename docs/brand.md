# Brand Tokens — Beacon & Co.

## Colors
```css
--forest: #2a4228;   /* primary — headers, CTAs, dark backgrounds */
--sage:   #7a9e72;   /* secondary — accents, the "& Co." wordmark treatment */
--gold:   #c49a48;   /* tertiary — highlights, the logo's origin-point dot */
--cream:  #fdfcf8;   /* base background */
--ink:    #1a1712;   /* body text */
--muted:  #8a8578;   /* captions, labels */
--rule:   #e2ddcf;   /* borders, dividers */
```

## Typography
- **Headlines:** Playfair Display (serif, weights 500–800)
- **Body/UI:** DM Sans (weights 400–700)
- **Labels/mono accents:** Geist Mono (small caps, letter-spaced, uppercase — used for eyebrow labels, tags, timestamps)

## Logo
`brand/beacon-and-co-brand-identity.svg` and `brand/beacon-logo-showcase.svg` are the source files — copy them into `public/brand/` as-is, do not regenerate or redraw them.

The mark: a gold origin point with three forest-green arcs sweeping outward and upward — deliberately **not** a lighthouse (avoids visual overlap with an unrelated company's registered trademark). Minimum display size: 32px, arcs still read as three distinct strokes at 16px favicon scale.

Lockup: "Beacon" in Playfair Display, "& Co." smaller, italic, sage-colored, directly beneath. "EST. WAYNESBORO, VA" as a thin tracked-out Geist Mono eyebrow line above, when there's room for it (nav bar: omit; hero, business card, signage: include).

## Voice
Warm, direct, honest about trade-offs — never oversells. Short sentences. States assumptions plainly. Never uses stock-photo cheerfulness or AI-avatar polish; leans into "real local, not a page mill" against every competitor.
